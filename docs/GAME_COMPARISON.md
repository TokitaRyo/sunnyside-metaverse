# 他のゲームとの比較と、楽しませる工夫・外す点

AMPLIFIRE（文化祭の2Dメタバース。ブラウザ・最大50人・歩く／チャット／エモート／スタンプラリー／NPC会話）を、似た体験のゲームと見比べて、
「取り入れられる点」と「外したほうがよい点」を整理し、実装したものを記録する。比較は遊び方の一般的な特徴についての制作者の整理で、各社の公式資料に基づくものではない。

## 比較した相手

| ゲーム | 似ているところ | 参考にした特徴 |
|---|---|---|
| Gather Town | ブラウザ・2D・近くの人と交流・マップ | 全体マップ、人数表示、場所に入ったときの案内 |
| どうぶつの森（ポケ森含む） | ゆったり歩く・住人との会話・イベント | 場所の名前の表示、効果音のごほうび、写真、感情表現 |
| ポケモンGO（スタンプ/ジム巡り）・スタンプラリー全般 | 場所を巡って集める | 次の目的地の矢印、達成のお祝い、残り数の見える化 |
| あつまれ/スターデューバレー | ドット絵・日常・コレクション | 小さな効果音、集めた物の図鑑、ささやかな演出（紙吹雪など） |
| Club Penguin / Habbo | 子ども向けの共有ワールド・エモート・チャット | 安全なエモート、定型のあいさつ、混んでいる場所 |
| ゼルダ・原神の探索 | 広い世界の探索 | 地名バナー、方位・目的地マーカー |
| VRChat / Roblox のイベントワールド | イベント会場の再現 | 写真撮影、案内、混雑の見える化 |

## 現状の強み（そのまま活かす）
- 出店ごとに作り込んだドット絵とNPC（会話・アニメ）。ほかのゲームに無い「文化祭そのもの」。
- スタンプラリーを、出店ごとの絵柄・影絵・取得時の演出にしてある。
- 軽い操作（歩く／走る／Enterでチャット／1〜6でエモート）と、スマホのパッド。
- サーバーは最小限（位置とチャット）で、50人でも軽い（計測済み）。

## 取り入れる（実装した）

| 工夫 | 参考 | 狙い | 実装 |
|---|---|---|---|
| 場所の名前バナー | ゼルダ・原神・どうぶつの森 | 出店に入ったときに名前が出て、「いまどこ」が分かる | 出店の区画を `map.areas` に持たせ、入ると上に名前を表示（`client/src/ui/AreaBanner.ts`） |
| ミニマップ | Gather Town・原神 | 35区画の島で迷わない。未取得スタンプと他の人の位置が見える | `client/src/ui/MiniMap.ts`（右上。Mキー／クリックで開閉） |
| スタンプの方位マーカー | 原神・ポケモンGO | 「次はどこ」が分かり、最後の1個まで遊び切れる | 一番近い未取得スタンプを指す矢印と距離（`client/src/ui/Compass.ts`） |
| 効果音（WebAudioで合成） | どうぶつの森・スターデュー | 取得・コンプリート・エモート・場所の切り替えに手ごたえ。素材の権利の心配がない | `client/src/game/sfx.ts`（BGMのミュートに連動） |
| コンプリートのお祝い | ポケモンGO・スタンプラリー全般 | 全部集めたときの達成感 | 紙吹雪＋ファンファーレ＋メッセージ（`client/src/ui/Confetti.ts`） |
| 写真を撮る | どうぶつの森・VRChat | 思い出を持ち帰り、SNSなどで広まる。写真美術部とも合う | 📷ボタン（画面を保存。ロゴ入り） |
| 参加人数の表示 | Gather Town | 「いま誰かいる」という安心感と賑わい | 左上に 👥 人数 |
| ハート・やったー（エモート） | Club Penguin・どうぶつの森 | 言葉が要らない前向きなあいさつ。頭の上に絵文字が出る | 後述の「外す」と入れ替え |
| はじめてのヒント | 多くのゲームのチュートリアル | 初見の人が、歩き方・スタンプ・エモートを知る | 初回だけ、短いヒントを順に表示 |

## 外す・変える

| 点 | 理由 | 対応 |
|---|---|---|
| エモート「攻撃」「やられる」 | 学校行事の場で、叩く・倒れるはいじめや乱暴に見えかねない。ほかのゲームの定番エモートも、子ども向けでは前向きなものが中心 | **削除**し、「ハート」「やったー」に置き換え |
| 本番での Colyseus Playground | 開発用の画面で、外から部屋に自由に入れてしまう | 本番では出さない（実施済み） |
| 出所不明のBGM 9曲 | 権利を確認できない。ゲームの雰囲気には大事だが、公開すると法的なリスクがある | **未対応（提案）**。出どころが分かるまで外す、または著作権フリーの曲に差し替えるのを推奨。外す手順は docs/LICENSES.md |
| 時間帯（朝・昼・夕方） | 暗くなって出店が見えにくい。要望により削除 | 削除済み |
| スタンプをブラウザの中だけに保存 | 履歴を消すと消える／不正もできる。賞品と結びつけるなら不向き | 現状は「遊び」として許容。景品にするなら、受付で見せる形にする（運用で対応） |
| 起動時の読み込みが長い（細かい画像が約800個） | 最初の印象が悪くなる（Roblox や Gather は素早く入れる） | 配信側のキャッシュを有効にして再訪を速くした。根本的には、画像を1枚にまとめる（アトラス化）改修が必要で、**提案**に残す |
| 入室演出が毎回流れる | 繰り返すと待たされる | クリックで飛ばせる（現状のまま）。2回目以降は短くする案は、見た目の好みなので変更しない |

## まだやっていない提案（優先順）
1. BGMの出どころ確認、または差し替え（権利）。
2. 画像のアトラス化（読み込みを数十リクエストに）。
3. 出店ごとの「ひとこと体験」（短いミニゲームや選択肢つきの会話）。いまの会話は一方通行。
4. 混雑の見える化（出店ごとの人数をミニマップに）。サーバー側で区画ごとの人数集計が要る。
5. 実績バッジ（歩いた距離、全部のNPCと話した、など）。
