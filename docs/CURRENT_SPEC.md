# AMPLIFIRE 現行仕様書

このリポジトリの**現在の姿**をまとめた仕様書です（2026-10-08 時点）。
最初に作った実装指示書は [SPEC.md](../SPEC.md)（素材仕様の実測値・同期方式の根拠は今もそちらが正）、
個々の判断の理由と計測結果は [docs/decisions.md](./decisions.md) にあります。この文書は「いま何ができて、どう動き、どこに何があるか」を1か所で分かるようにしたものです。

---

## 1. 概要

- **名前**: AMPLIFIRE（旧称 Sunnyside World。素材パックの名前としては Sunnyside World を使い続ける）。
- **何か**: ブラウザで遊ぶ2Dのメタバース。文化祭の各団体の出し物を、空に浮かぶ1つの大きな島の上に出店として並べて再現し、来場者がキャラクターで歩き回り、チャットし、NPCと話し、スタンプを集める。
- **規模**: 同時接続 最大 50 人、単一ルーム（満員のときは別部屋を作らず「満員です」で断る）。
- **本番**: https://sunnyside-metaverse.fly.dev （Fly.io、東京リージョン）。`main` への push で自動デプロイ。
- **対象端末**: PC（キーボード）とスマホ（バーチャルパッド）。

## 4. ゲームの流れ

1. **入室画面**: 宇宙背景＋惑星＋ロゴ。なまえ（12文字まで）と髪型6種（bowl / curly / long / mop / short / spikey）を選ぶ。設定は端末に保存。
2. **入室演出**（約4.7秒。クリック/キーで飛ばせる）: パネルとロゴが消え、惑星へ降下 → マップ全体を引いた衛星映像（グリッド・照準・高度表示）→ 自分のキャラまでズームイン → 操作開始。時間割は `client/src/ui/intro.ts`。
3. **プレイ**: 広場から出発して、島の上の出店を歩いて回る。チャット・エモート・NPCとの会話・スタンプ集め。

## 5. 世界と物理

- タイル 16px。キャラのフレームは 96×64、足元の当たり判定は 12×8、体は約 16px 四方。
- 速度: 歩き 64 px/s、走り 112 px/s。向きは左右のみ。
- 衝突の唯一の情報源は `map.json` の `layers.collision`（1=通れない）と、配置物の `hit`（足元基準の矩形）。クライアントの `blocked()` とサーバーの `isFootBlocked` が同じ情報を使う。
- 描画順: 床タイル → 床の配置物（`sort:"floor"`）→ 足元Yで前後が決まるもの（キャラ・木・建物のタイル行・`sort:"y"` の配置物）→ 最前面（雲）。
- カメラ: 整数倍ズーム（2〜3倍）。入室演出の間だけ小数倍に引く。

## 6. 通信とサーバー（権威は部分的）

- **移動はクライアント主導**。クライアントは 15Hz で `{x, y, flipX, action}` を、変化したときだけ送る。サーバーは速度上限だけ検証する（根拠は SPEC 4.1）。
  - 許容: 最大速度 × 1.5 倍の「予算」を 0.5 秒ぶんためるトークンバケット（バースト受信でも誤棄却しない）。範囲外・超過は棄却し、本人にだけ `correct` で正しい座標を返す。
  - 壁抜け等の位置検証はしない（展示用途のため。検証済みの範囲は decisions.md）。
- **状態**: `Player { name, hair, x, y, flipX, action }` を Colyseus Schema で同期（patchRate 50ms=20Hz）。他プレイヤーは補間して描画（`REMOTE_SMOOTHING`、96px 超は瞬間移動）。
- **メッセージ**: C→S `move` / `chat` / `emote`、S→C `chat` / `emote` / `correct`（速度超過などで棄却した本人にだけ、正しい座標を返す）。
- **チャット**: 140文字まで・1人 毎秒2通まで。制御文字を除去し、NGワード（暴言・脅迫・差別語・下ネタ）を「＊」に伏字。吹き出しは 4 秒、ログは 50 行。
- **切断**: 想定外の切断は 15 秒まで同じキャラで復帰を待つ。タブを閉じると即退室。
- **配信**: ビルド済みクライアントを同じサーバーが配信（`ws/https` の混在回避）。開発時は Playground。

## 7. マップデータ `client/src/config/map.json`

本番マップはこの1ファイルが真実。**Git管理外**（素材と同じ扱い）。起動時に `validate.ts` で検証し、問題は画面とコンソールに出す。エディタの「保存」で書き換える（保存前に `reference/map-backups/` へ自動退避）。

| キー | 内容 |
|---|---|
| `width` `height` `tileSize` | マップ寸法（現在 115×77 マス、16px） |
| `tilesets` / `tileLayers` | タイルセット（main=16px・forest=32px）と、名前つきレイヤー13枚。`mode`: floor（床）/ ysort（行ごとに前後判定）/ top（最前面） |
| `layers.collision` | 衝突マス（唯一の衝突の情報源） |
| `sprites` | 配置物のスプライト定義。`file`・`fw/fh`・`frames/fps`・`ox/oy`（原点）。`crop`=タイルセットの切り出し、`catalog:true`=エディタ用見本（使われていなければゲームは読まない） |
| `objects` | 配置物（px座標・`by`=足元Y・`sort`・`hit/hx`・`sx/sy/angle`・`frame/speed`・`npc`・`group`） |
| `groups` | タイルで貼った塊（島・パーツ・スタンプ）。1つの物として選択・移動・削除できる |
| `keyItems` | スタンプラリーのキーアイテム `{id,x,y,name?}` |
| `spawn` | スポーン位置（マス） |
| `props` `mobs` `layers.ground/deco/overhead` | 旧形式の互換（現在は未使用・空） |

### 配置物の拡張

- **NPC**: `npc:{ name?, lines[] }`。`lines` の1要素が1ページ。足元から 40px 以内で「話す」ボタン、64px 以上離れると閉じる。会話中は自分の移動を止める。頭上に「💬 名前」。
- **回転**: `angle`（度・時計回り。0 は省略）。当たり判定の矩形は回転しない。
- **タイルの絵**: `sprites[...].crop` で、タイルセット画像の一部を1つの物として置ける（果物・家具・鉱石など約200種を自動検出して一覧に出す）。
- **専用ドット絵**: `file:"../brand/stall/xxx.png"`（アニメは横一列のシートで `frames/fps`）。

## 8. 現在のマップ

- 空の背景に雲、**大きな島1つ**（グループ名「文化祭島」。88×37マス、草の面は 86×34マス＝1376×544px）。ワープ機能はなくなり、島の上を歩いて回る。
- 草の面を **6列×3行の区画**（各 192×128px、左右 32px・上下とも通路）に分け、区画ごとに出店を置く。区画の割り当ては `scripts/build-stalls.mjs` の `SLOTS`。
  - 上の列（部活・委員会）: おばけやしき・カジノ・吹奏楽部・プログラミング部・科学部（ロボット展示）・図書委員会
  - まん中の列: クラゲファクトリー・茶華道部・**広場（スポーン地点）**・カフェ・射的・チョコバナナ
  - 下の列（食べ物）: たこ焼き・お好み焼き・油そば・たい焼き・わたあめ・ポテト
- 広場には案内係のNPC（どの列に何があるかを話す）と休憩のテーブル・椅子・花の鉢だけがある。
- スタンプ（星）は出店ごとに1つ、その区画の右どなりの通路にある（広場はなし）。全部で 17 個。
- 白紙から作り直す手順: `node scripts/rebuild-festival.mjs`（空・雲・島・出店・広場・スタンプまで一括。今のマップは `reference/map-backups/` に退避）。島だけなら `node scripts/gen-sky.mjs <map.json> --single 84x32 --label 文化祭島`。
- 出店（各島1つ。詳細は §10）: お好み焼き=27、たい焼き=26、カフェ=25、チョコバナナ=20、たこ焼き=19、射的=24、コンサート会場=30、茶華道部=13、油そば=14、わたあめ=16、ポテト=17、カジノ=18、おばけやしき=7、プログラミング部=8、科学部（ロボット展示）=9、ハンドメイド（夜のクラゲ）=10。ほか、利用者が手で作った島・NPC（わたあめ屋の受付、スケルトンの部屋など）がある。
- 生成物: 空と島は `scripts/gen-sky.mjs`、島のタイルの自然な配置は `scripts/retile.mjs`。

## 9. 機能の詳細

### 9.1 スタンプラリー
- キーアイテム（星）を島ごとに1つ置く。足元が中心から 18px 以内に来ると**自動で取得**。星は上下にゆれ、取ると跳ねて消える。
- 記録は端末の localStorage（`sunnyside.stamps.v1`）のみ。サーバーには送らない。マップから消えたIDは数えない。
- 左上の「★ n/N」ボタンでスタンプカード（枠はキーアイテム数ぶん）。全部そろうとコンプリート表示。カードの「はじめから」で消去。

### 9.2 NPCとの会話
§7 の `npc` と §4 の操作を参照。会話UIは DOM（`Talk.ts`）で、1文字ずつ表示、途中で押すと全文表示。

### 9.3 BGM・音
- `client/src/audio/Bgm.ts`。素材は `assets/audio/` の mp3。入室ボタンのクリックで開始（自動再生制限を回避）。左上のボタンでミュート（記録あり）。

### 9.4 入室画面・タイトル
- 宇宙・RGB・ドット絵。画像は `client/public/brand/` の `amplifire-logo.png`（利用者提供のロゴ）、`space-bg.png` と `earth.png`（`scripts/gen-brand-assets.mjs` が固定シードで生成）。

## 10. マップエディタ（開発時のみ・`?edit=1`）

Phaser のシーンとして動く。プレイとの切り替えは右上のボタン。

| ツール | キー | 内容 |
|---|---|---|
| 選択・移動 | V | 物・島（グループ）をクリックで選択、ドラッグで移動、矢印キーで微調整（Shiftで速く）、インスペクタで数値・当たり判定・セリフ・回転を編集 |
| 物を置く | O | 分類（ゴブリン・スケルトン・人間・動物・物）＋「タイルの絵」。Q/Shift+Q で回転、「床に敷く」、影も一緒に置く |
| パーツ | G | 建物・自然物・柵など、タイル＋当たり判定＋付属物をまとめて置く |
| 範囲選択 | B | 矩形で一括削除／複製して「スタンプ」で何度でも置く |
| 消す | E | そのマスの全レイヤー・当たり判定・物を消す |
| キーアイテム | K | 星を置く／動かす／消す。「島ごとに自動配置」 |
| 衝突 | C | 通れない/通れるを塗る |
| タイル | T | レイヤーを選び、パレットからタイルを塗る |
| スポーン | P | スポーン位置 |

共通: F=左右反転、N=複製、Delete=削除、Ctrl+Z/Y=元に戻す/やり直し、Ctrl+S=保存、ホイール=ズーム、ドラッグ/中ボタン/スペースで移動。表示切替: 衝突・判定枠・グリッド・物・プレイ画面の範囲（スマホ）・レイヤー別。島（グループ）を動かすと、付属の物・上の星も一緒に動く。

## 11. 出店（団体の再現）

- 1出店＝`scripts/stalls/<id>.ps1`（オリジナルのドット絵を描く。Windows 専用）＋`scripts/stalls/<id>.mjs`（配置）。決まりごとは [scripts/stalls/README.md](../scripts/stalls/README.md)。
- 組み立て: `node scripts/build-stalls.mjs [--only=id,...] [--replace] [--dry]`（`map.json` を書き換える。自動バックアップ）。確認だけなら `node scripts/preview-stall.mjs <id>`。素材調べは `node scripts/stall-assets.mjs`。
- 現在 17 出店と広場（§8）。看板・食べ物や展示物・店主NPC・客NPC・アニメ付き。セリフに値段・時間・場所など事実は入れていない（分かれば差し替える）。
- 場所は区画（`SLOTS`）で決まる。`meta` に島は書かない。組み立ては `node scripts/build-stalls.mjs`（区画に配置物が既にあれば飛ばす。`--replace` で作り直す）。

## 12. 素材とライセンス

- 素材パック **Sunnyside World Asset Pack V2.1**（danieldiggle, itch.io）は**再配布禁止**。公開リポジトリには含めず、`client/public/assets/` と `map.json` は Git管理外。
- オリジナルのドット絵（`client/public/brand/`）は Git管理で、素材パックの絵を写していない。
- フレーム数・寸法は実測値で `sprites.json` / `tileset.json` に定義済み（SPEC 3 章）。コードに直書きしない。

## 13. デプロイ

- `main` への push → GitHub Actions（`.github/workflows/deploy.yml`）→ Fly.io（`sunnyside-metaverse`、nrt、shared-cpu-1x / 512MB、常時1台）。
- 素材と `map.json` は、公開リポジトリにないため、**非公開リポジトリ `TokitaRyo/sunnyside-metaverse-assets`** から、ビルド直前に読み取り専用の Deploy Key で取得して配置する。
  → **手元で作ったマップ（出店・島）を本番に出すには、その非公開リポジトリの `client/src/config/map.json`（と、増えた素材）を更新する必要がある**。公開リポジトリへの push だけでは、マップは変わらない。
- オリジナルのドット絵（`client/public/brand/`）は公開リポジトリ側にあるので、push で本番に出る。
- 秘密情報（`ASSETS_DEPLOY_KEY`・`FLY_API_TOKEN`）は GitHub の Secrets。

## 14. 非機能・運用

- 負荷: bot 30 体で描画 60fps・受信 約 3.9KB/s/人（計測は decisions.md）。満員(50)は `loadtest` で拒否を確認済み。
- 開発用ブラウザ（埋め込みペイン）はフレームが間引かれるため、実時間の挙動（入室演出の長さなど）は実ブラウザで見る。
- スマホ: バーチャルパッドは `(pointer: coarse)` か `?pad=1` で表示。

## 15. 既知の制限・未対応

- ワープ機能は廃止した（島は1つ）。
- スタンプの記録は端末内のみ。ブラウザを変える・履歴を消すと最初から（不正も可能）。
- クライアント主導の移動なので、壁抜けなど位置の不正はサーバーでは検出しない（速度のみ検証）。
- NGワードフィルタは簡易（完全なモデレーションではない）。
- 重なったグループ（同じタイルIDの島どうしが重なる配置）は、元に戻すで完全には戻らないことがある。
- 出店のセリフは一般的な内容のみ（団体の実情報は未入力）。人物に座る・銃を構える等のポーズ素材がない。
- 本番マップは非公開リポジトリ経由のため、公開リポジトリだけでは再現できない（素材ライセンスのため）。
