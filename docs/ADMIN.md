# 管理ページと、同意・データの取り扱い

運営者だけが見られる管理ページ（`/admin`）と、入室時の同意（利用規約）の仕様と、使い方。

## 1. 使えるようにする（最初の1回）

管理ページは、**パスワードを設定するまで存在しないことになる**（`/admin` は 404）。本番で使うには、あなたが決めたパスワードを Fly.io に登録する。

```bash
fly secrets set ADMIN_PASSWORD="（10文字以上の、推測されにくいパスワード）" -a sunnyside-metaverse
```

- 登録するとサーバーが自動で再起動する（入室中の人は少しの間つながり直す）。
- パスワードは、他人に教えない・チャットや画面共有に出さない・GitHub に書かない。忘れたら、同じコマンドで新しいものに変えればよい。
- 開くのは `https://sunnyside-metaverse.fly.dev/admin/`。ブラウザがユーザー名とパスワードを聞くので、ユーザー名は何でもよく（空でも可）、パスワードだけ入力する。
- 間違いが8回続くと、その接続元は10分間、受け付けなくなる。

手元（開発）で試すとき: `ADMIN_PASSWORD` を環境変数に入れてから `npm run dev`、`http://localhost:2567/admin/` を開く。

## 2. 記録を残す（Volume）

記録は、サーバーの `DATA_DIR`（無ければ `/data` があれば `/data`、なければ `./data`）に、1行1件の JSON（`sessions.jsonl`・`chat.jsonl`・`online.jsonl`・`bans.json`）で書く。

**Fly.io の標準の状態では、再起動やデプロイで消える。** デプロイしても記録を残したいときは、次を行う（費用はごくわずか）。

```bash
fly volumes create amplifire_data --size 1 --region nrt -a sunnyside-metaverse
```

そのうえで `fly.toml` に次を足して、デプロイする。

```toml
[mounts]
  source = "amplifire_data"
  destination = "/data"
```

Volume が付くまでは、管理ページの上に「保存先は一時的な場所の可能性」と警告が出る。文化祭の当日は、**当日までに Volume を付けておくことを勧める**（当日の途中でデプロイすると、それまでの記録が消えるため）。

## 4. 集めるもの・集めないもの

- 集める: ニックネーム、髪型、チャット（日時つき）、入室・退室の時刻と滞在時間、出店の区画ごとの滞在時間、スタンプの数、エモートの回数、端末の種類（パソコン／スマホ等）、ブラウザのランダムな訪問者ID、同意した規約の版。
- 集めない: 本名・連絡先・位置情報・IPアドレス（運営の記録には残さない。接続元は、ログイン失敗の制限・回線ごとの人数や入室の回数・自動の停止のために、メモリにだけ持つ）。位置の履歴（出店ごとの合計時間だけ）。
- **自動対応の記録**（荒らし対策。docs/ADMIN.md §7）は、**メモリにだけ**持ち、ファイルには書かない（再起動で消える）。内容は、時刻・種類・ニックネーム・訪問者IDの先頭・理由の短い説明だけで、**送れなかった書き込みの本文は残さない**（連絡先が入っていることがあるため）。通報した人の情報も、メモリにだけ、一時的に持つ。
- 保存期間は **30日**（`shared/constants.ts` の `DATA_RETENTION_DAYS`）。過ぎた記録は、サーバーの起動時と6時間ごとに自動で消える。
- 「人数」は端末（ブラウザ）で数える。別のブラウザ・履歴の消去・シークレットウィンドウでは別の人になる。
- スタンプの数は参加者の画面からの申告で、不正はできる。景品にするなら、受付で画面を見せてもらう。

## 5. 同意（利用規約）

- 入室画面に、チェックボックス「利用規約とデータの取り扱いに同意します」がある。リンクから規約の全文（`client/src/ui/terms.ts`）が開く。**同意するまで、入室ボタンは押せない。**
- 同意はブラウザに「規約の版つき」で記録する（`amplifire.consent`）。同じ版なら、次からはチェック済みで始まる。
- **サーバーも確認する**: 入室のとき、同意した版（`CONSENT_VERSION`）が合っていない接続は、サーバーが断る（同意なしで記録されることはない）。
- 規約の文面を変えたら、`shared/constants.ts` の `CONSENT_VERSION` を新しい日付にする。全員がもう一度同意することになる。
- 規約にある問い合わせ先は `shared/constants.ts` の `OPERATOR_CONTACT`。**実際の連絡先に書き換える。**
- 規約の画面には、本人の「訪問者ID」が出る。本人から確認・削除の申し出があったら、このIDを聞いて、管理ページの「運営の操作」で削除する。
- この規約は学校行事向けのひな形。使う前に、学校・主催者（必要なら法律の詳しい人）の確認を受けること。

## 6. 守りのしくみ

- `ADMIN_PASSWORD` が未設定・10文字未満なら、管理ページは無効（404）。
- パスワードの照合は、時間差から推測されにくい方法（定時間比較）。間違いが続くと接続元を一時的に締め出す。
- 変更を伴う操作（おしらせ・退室・利用停止・削除）は、専用のヘッダーと JSON が必要で、他のサイトのページから勝手に実行できない。
- 管理ページの画面は、自分のサーバーの JS/CSS だけを読み込む（CSP）。チャット本文は文字として出すので、書かれた HTML や CSV の式は動かない。
- 検索エンジンに載らない（noindex）、画面の埋め込みも禁止。
- 利用停止は「訪問者ID」単位。ブラウザの履歴を消す・別のブラウザを使うと入れてしまう（簡易的なもの）。
- **国別IP制限**: 既定では、**日本（JP）以外からのアクセスは、ページも入室も断る**（403）。接続元は、Fly.io が付ける Fly-Client-IP（外から偽装できない）で判断し、手元（localhost・社内LANなど）はいつも通す。IPと国の対応は geoip-country（MaxMind GeoLite2）のデータで、完全ではない（VPN・プロキシは見抜けない／まれに日本の回線が「国不明」になる。国不明は通す）。環境変数で変えられる: ALLOW_COUNTRIES=JP,US（許可する国。カンマ区切り）、GEO_BLOCK=0（無効にする）、GEO_BLOCK_UNKNOWN=1（国不明も断る）。**管理ページ・ショー画面も同じ制限を受ける**ので、海外から運営するときは、先に ALLOW_COUNTRIES へ足しておく（flyctl secrets set ALLOW_COUNTRIES=JP,<国コード>）。データは、パッケージを上げるたびに新しくなる。
- **人数まわりの設定**（環境変数。flyctl secrets set / fly.toml）: MAX_CLIENTS（同時に入れる人数。既定150）、MAX_PER_IP（同じ回線から入れる数。既定50。学校のWi-Fiなど同じ回線の人が多いときは増やす）。ログに [health] players=… cpu=…% lagP99=… が15秒ごとに出る（flyctl logs）。cpu が 80〜100% に近い、または lagP99 が 100ms を超えるなら、VM を大きくする（flyctl scale vm performance-1x --memory 1024）。[slow] は、回線が詰まった接続を切り離したしるし。


## 7. 荒らし対策（当日、モデレーターがいなくても）

運営がずっと見ていなくても、荒らしが得をしないように、**自動で**止める。3つの層でできている（実装は `server/src/moderation.ts`）。

### 7.1 荒らしが得をしない作り（予防）
- **名前の検査**: 暴言・連絡先・URL・運営のなりすまし（「運営」「管理」「おしらせ」「先生」「公式」「system」「admin」など）は使えず、「ゲスト＋数字」に置き換わる。すき間・記号・全角半角・かなの種類を変えた言い換えも見つける（英語の語の一部（badminton など）は巻き込まない）。ショー画面にも、この検査を通った名前だけが出る。
- **新しい人はすぐには書けない**: 入室から15秒（スタンプを1つ取ればすぐ）は、チャットできない。使い捨てのボット・入り直しの荒らしへの手間になる。
- **連絡先・URL・SNS は送れない**: URL・メールアドレス・@ID・電話番号（すき間を入れても）・「LINE／インスタ／ディスコード…」と「交換／教えて…」の組み合わせは、送れない（子どもが参加するため）。
- **NGワード**: そのまま入っているものは「＊」に伏字。すき間・記号・かなの種類で言い換えたものは、送らない。「ばか」「うざい」のような軽い言葉は伏字だけ（ふつうの文を巻き込まないよう、言い換えの検出には使わない）。
- **連投の抑え**: 書き込みは3秒に1通まで、同じ文は30秒続けて送れない、同じ文字の長い繰り返しは送れない、長い同じ文を5人以上が一斉に流したら止める。エモートは1秒に1回まで。

### 7.2 自動で止める
- **違反の点数**: 連絡先・NGワードなどの違反に点が付き、10分で3点たまると、その人のチャットを止める（**1回目 10分 → 2回目 1時間 → 3回目以降 その日の終わりまで**）。2回目以降は、同じ回線のチャットも30分止める（履歴を消して入り直す荒らし対策。会場の Wi-Fi など共有の回線への巻き添えを減らすため、重いときだけ）。止まっている人には、理由が画面に出る。
- **全体の安全装置**: 直近1分に、**別々の3人以上**から、違反が10件以上出たら、全員のチャットを**「定型文だけ」**（10個のボタン）に自動で切り替える。5分たつと自動で戻る（30分以内にまた働くと、2回目は10分・3回目は15分）。1人の荒らしでは働かない（全員のチャットを止められないように）。あいさつ（「こんにちは」）が重なっただけでは、違反に数えない。
- **入室の制限**: 同じ回線から、1分に10回まで。運営が退室させた人は、2分間、入り直せない。
- **通報**: 他の参加者の名前を押すと、「ブロック／通報」のメニューが出る。**別々の3人**から5分以内に通報された人は、自動でチャットが止まる（入室から30秒たっていない人の通報は数えない。1人が出せるのは10分に3回まで）。
- **会場限定モード（任意）**: 環境変数 `VENUE_CODE`（6文字以上の合言葉）を設定すると、入室には、会場の QR コード（URL の `?k=…`）が要る。ページを開くだけならだれでもできるが、入室できるのは、QR を読みとった人だけ。管理ページの「自動対応」タブの「印刷用ページ」（`/admin/venue`）で QR を印刷できる。`VENUE_ROTATE_MIN`（分）も設定すると、コードがその間隔で変わり、**ショー画面の右下に、いまの入室用 QR が出る**（会場にいる人だけが見られる）。

### 7.3 参加者が自分で守れる
- **ブロック**: 名前を押して「見えなくする」と、その人の絵・名札・ふきだし・チャット・エモートが、自分の画面から消える（自分の画面だけ。この接続のあいだ有効）。
- **通報**: 上のとおり。通報した人には、受け付けた知らせが届く。

### 7.4 ショー画面（会場の大画面）の安全側の設定
- **発言のふきだしは、既定で出さない**（操作パネルの💬、または B キーで出せる）。
- **入室から30秒たった人だけ**を映す（入ってすぐの荒らしが、大画面に映らないように）。

### 7.5 管理ページ「自動対応」タブ
- いまの状態（ふつう／定型文だけ）、止めている人（「解除」ボタン）、最近の自動対応（新しい順。書き込みの本文は記録しない）、会場限定モードの URL。
- **「定型文だけにする（手動）」** のボタン: 荒らしが出たら、ワンタッチで全員を定型文だけにできる（もう一度押すと解ける）。ヘッダーの「チャット停止」（全員が書けない）とは別。
- 環境変数 `ALERT_WEBHOOK_URL`（https の Webhook。Discord・Slack 互換）を設定すると、安全装置が働いたときに、運営のチャットへ通知が届く（個人の情報は載らない。1分に1回まで）。

### 7.6 設定（環境変数。試験用に変えられる）
| 名前 | 既定 | 意味 |
|---|---|---|
| `MOD_NEWCOMER_SEC` | 15 | 入室してから書けるまでの秒数 |
| `MOD_CHAT_GAP_SEC` | 3 | 書き込みの間隔（秒） |
| `MOD_STRIKE_LIMIT` | 3 | 10分でこの点数になると、チャットを止める |
| `MOD_BREAKER_THRESHOLD` | 10 | 安全装置: 直近1分の違反の数 |
| `MOD_BREAKER_MIN_PEOPLE` | 3 | 安全装置: 違反が出ている「別々の人」の数 |
| `MOD_BREAKER_SEC` | 300 | 安全装置が働く時間（秒） |
| `MOD_JOIN_PER_MIN` | 10 | 同じ回線からの入室（1分あたり） |
| `MOD_REPORT_NEEDED` | 3 | 自動で止めるための、通報した人の数 |
| `MOD_REPORTER_MIN_SEC` | 30 | 通報できるようになるまでの秒数 |
| `VENUE_CODE` / `VENUE_ROTATE_MIN` | なし | 会場限定モード |
| `ALERT_WEBHOOK_URL` | なし | 安全装置の通知先 |

### 7.7 確認のしかた（試験）
- `npm run troll-test`: 荒らしのふりをするボットで、名前・新しい人の待ち・連絡先・NGワードの言い換え・連投・エモート連打・点数による停止・定型文・通報・安全装置（自動の入り切り）・手動の定型文だけ・退室後の待ち・入室のしすぎ・会場限定モードを確かめる（約1分半。試験用の一時的なサーバーを自動で起動する）。`scripts/moderation-corpus.ts` は、ふつうの会話や名前が誤って止まらないことを確かめる（文を足せる）。

### 7.8 限界（正直に）
- **VPN・国内の踏み台を使う荒らし**、**履歴を消して別の端末で入り直す荒らし**は、完全には止められない。新しい人の待ち・点数・回線の止め・通報で、「やる気をくじく」のが目標。
- NGワードは完全ではない（新しい言い回しは、リストに足す: `server/src/moderation.ts` の `NG_WORDS`）。伏字になった普通の言葉が出ることがある。
- ブロックは、自分の画面だけ（この接続のあいだ）。通報の集団利用（徒党）を避けるため、別々の端末の3人以上が必要。
- 当日は、**まず「会場限定モード」にするのが、いちばん確実**（会場の人だけが入れる）。遠くの人にも遊んでほしいときは、自動の対策だけで運用する。

## 8. 本番リンクを「関係者だけ」にする（合言葉の入り口）

- **既定で有効**: 本番（Fly.io）では、`ADMIN_PASSWORD` が設定されていれば、**サイト全体が、合言葉のログイン画面の内側**になる。合言葉を知っている人（＝管理者パスワードを知っている運営者）だけが、ページも、素材も、入室も使える。知らない人が URL を開くと、ログイン画面（合言葉の入力）だけが出る。
- **合言葉**: 既定は、`ADMIN_PASSWORD`（10文字以上）と同じ。別にしたいときは、`flyctl secrets set SITE_PASSWORD=…`（10文字以上）。
- **入りかた**: ログイン画面で合言葉を入れると、30日間有効な Cookie（署名つき・HttpOnly）が付く。スマホ・パソコンごとに1回。管理ページ（`/admin`）にパスワードで入った端末は、自動でこの Cookie も付く（ショー画面が、画像や接続を使うため）。ログアウトは `/__gate/logout`。合言葉を変えると、すべての Cookie が無効になる。
- **何が守られるか**: ページ・素材（画像・BGM）・入室の予約（`/matchmake`）・WebSocket のすべて（Cookie がなければ、すべて断る）。管理ページは、独自の認証（Basic）。ショー画面の観客の接続は、観客トークン。国別制限（日本のみ）も、そのまま働く。
- **合言葉のまちがい**: 同じ回線から、10分に8回まちがえると、一時的に止める（429）。
- **文化祭の当日に、みんなに開くとき**: `flyctl secrets set SITE_LOCK=0`（再起動される。いまいる人は、いったん切れる）。もとの「関係者だけ」に戻すときは、`flyctl secrets unset SITE_LOCK`。※ 当日の前に、**まず、自分の端末で、ログイン画面から入れることを確認しておく**こと（合言葉を忘れたときは、`flyctl secrets set ADMIN_PASSWORD=…` か `SITE_PASSWORD=…` で決め直せる）。
- 手元の開発・試験では、既定で無効（`SITE_LOCK=1` のときだけ有効）。
