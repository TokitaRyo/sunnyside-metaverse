# 管理ページと、同意・データの取り扱い

運営者だけが見られる管理ページ（`/admin`）と、入室時の同意（利用規約）の仕様と、使い方。

## 1. 使えるようにする（最初の1回）

管理ページは、**パスワードを設定するまで存在しないことになる**（`/admin` は 404）。本番で使うには、あなたが決めたパスワードを Fly.io に登録する。

```bash
fly secrets set ADMIN_PASSWORD="（10文字以上の、推測されにくいパスワード）" -a sunnyside-metaverse
```

- 登録するとサーバーが自動で再起動する（入室中の人は少しの間つながり直す）。
- パスワードは、他人に教えない・チャットや画面共有に出さない・GitHub に書かない。忘れたら、同じコマンドで新しいものに変えればよい。
- 開くのは `https://sunnyside-metaverse.fly.dev/admin/`。ブラウザがユーザー名とパスワードを聞くので、ユーザー名は何でもよく（空でも可）、パスワードだけ入力する。
- 間違いが8回続くと、その接続元は10分間、受け付けなくなる。

手元（開発）で試すとき: `ADMIN_PASSWORD` を環境変数に入れてから `npm run dev`、`http://localhost:2567/admin/` を開く。

## 2. 記録を残す（Volume）

記録は、サーバーの `DATA_DIR`（無ければ `/data` があれば `/data`、なければ `./data`）に、1行1件の JSON（`sessions.jsonl`・`chat.jsonl`・`online.jsonl`・`bans.json`）で書く。

**Fly.io の標準の状態では、再起動やデプロイで消える。** デプロイしても記録を残したいときは、次を行う（費用はごくわずか）。

```bash
fly volumes create amplifire_data --size 1 --region nrt -a sunnyside-metaverse
```

そのうえで `fly.toml` に次を足して、デプロイする。

```toml
[mounts]
  source = "amplifire_data"
  destination = "/data"
```

Volume が付くまでは、管理ページの上に「保存先は一時的な場所の可能性」と警告が出る。文化祭の当日は、**当日までに Volume を付けておくことを勧める**（当日の途中でデプロイすると、それまでの記録が消えるため）。

## 3. 見られるもの

| チャット履歴 | 新しい順。ことば・ニックネーム・訪問者IDで探せる。IDをクリックすると、その人の発言だけ。CSV で保存できる。**発言を選んで削除**できる（行をタップで選ぶ／「表示中をすべて選ぶ」→「選んだ発言を削除」。記録と、入室中の人の画面の両方から消える） |

**ショー画面**（`/admin/show`。管理ページ右上の「🎬 ショー画面」から。パスワードの内側）: 大型ディスプレイやプロジェクター用。**主役（左）は、いま入室中の人の「ゲーム画面」**で、その人のキャラをカメラが追いかける（名前の札・ふきだし・まわりの人も見える。切り替えるときは、島を引いて見せてから寄る）。**右**に、入室画面と同じ白いパステルのデザインで、その人の名前・アバター・スタンプ数（進み具合の線つき）・滞在時間（1秒ずつ進む）・おしゃべりの回数・いる場所を出す。**下**に、参加している人のキャラクターを並べる（入室すると上から弾んで出る。クリックでその人に切り替え）。操作: マウスを動かすと下に操作パネルが出る（前へ／次へ／一時停止・切り替え間隔（既定15秒）・順番をばらばらに・一覧の表示・全画面）。キー: ←→ 前後、スペース 一時停止、F 全画面、S ばらばら、T 一覧。だれもいないときは、島ぜんたいと見本のアバターを出す。`n`n仕組み: ショー画面は、ゲームの部屋に「観客」としてつなぐ（プレイヤーとしては出ず、人数にも記録にも入らない。ただし接続の枠は1つ使う）。観客の入場券は、パスワードの内側の API（`/admin/api/spectator-token`）が出す5分だけ使える署名つきトークンで、パスワードを知らない人は作れない。`n`n**チャットの停止**: ヘッダーの「💬 チャット: 開放中」ボタンを押すと、全員のチャットが止まる（確認なしのワンタッチ。もう一度押すと再開）。停止中の入室者にも止まった状態で届く。止まっていても、記録・削除・おしらせは使える。

## 4. 集めるもの・集めないもの

- 集める: ニックネーム、髪型、チャット（日時つき）、入室・退室の時刻と滞在時間、出店の区画ごとの滞在時間、スタンプの数、エモートの回数、端末の種類（パソコン／スマホ等）、ブラウザのランダムな訪問者ID、同意した規約の版。
- 集めない: 本名・連絡先・位置情報・IPアドレス（運営の記録には残さない。接続元は、ログイン失敗の制限のためメモリにだけ数分間持つ）。位置の履歴（出店ごとの合計時間だけ）。
- 保存期間は **30日**（`shared/constants.ts` の `DATA_RETENTION_DAYS`）。過ぎた記録は、サーバーの起動時と6時間ごとに自動で消える。
- 「人数」は端末（ブラウザ）で数える。別のブラウザ・履歴の消去・シークレットウィンドウでは別の人になる。
- スタンプの数は参加者の画面からの申告で、不正はできる。景品にするなら、受付で画面を見せてもらう。

## 5. 同意（利用規約）

- 入室画面に、チェックボックス「利用規約とデータの取り扱いに同意します」がある。リンクから規約の全文（`client/src/ui/terms.ts`）が開く。**同意するまで、入室ボタンは押せない。**
- 同意はブラウザに「規約の版つき」で記録する（`amplifire.consent`）。同じ版なら、次からはチェック済みで始まる。
- **サーバーも確認する**: 入室のとき、同意した版（`CONSENT_VERSION`）が合っていない接続は、サーバーが断る（同意なしで記録されることはない）。
- 規約の文面を変えたら、`shared/constants.ts` の `CONSENT_VERSION` を新しい日付にする。全員がもう一度同意することになる。
- 規約にある問い合わせ先は `shared/constants.ts` の `OPERATOR_CONTACT`。**実際の連絡先に書き換える。**
- 規約の画面には、本人の「訪問者ID」が出る。本人から確認・削除の申し出があったら、このIDを聞いて、管理ページの「運営の操作」で削除する。
- この規約は学校行事向けのひな形。使う前に、学校・主催者（必要なら法律の詳しい人）の確認を受けること。

## 6. 守りのしくみ

- `ADMIN_PASSWORD` が未設定・10文字未満なら、管理ページは無効（404）。
- パスワードの照合は、時間差から推測されにくい方法（定時間比較）。間違いが続くと接続元を一時的に締め出す。
- 変更を伴う操作（おしらせ・退室・利用停止・削除）は、専用のヘッダーと JSON が必要で、他のサイトのページから勝手に実行できない。
- 管理ページの画面は、自分のサーバーの JS/CSS だけを読み込む（CSP）。チャット本文は文字として出すので、書かれた HTML や CSV の式は動かない。
- 検索エンジンに載らない（noindex）、画面の埋め込みも禁止。
- 利用停止は「訪問者ID」単位。ブラウザの履歴を消す・別のブラウザを使うと入れてしまう（簡易的なもの）。
- **国別IP制限**: 既定では、**日本（JP）以外からのアクセスは、ページも入室も断る**（403）。接続元は、Fly.io が付ける Fly-Client-IP（外から偽装できない）で判断し、手元（localhost・社内LANなど）はいつも通す。IPと国の対応は geoip-country（MaxMind GeoLite2）のデータで、完全ではない（VPN・プロキシは見抜けない／まれに日本の回線が「国不明」になる。国不明は通す）。環境変数で変えられる: ALLOW_COUNTRIES=JP,US（許可する国。カンマ区切り）、GEO_BLOCK=0（無効にする）、GEO_BLOCK_UNKNOWN=1（国不明も断る）。**管理ページ・ショー画面も同じ制限を受ける**ので、海外から運営するときは、先に ALLOW_COUNTRIES へ足しておく（lyctl secrets set ALLOW_COUNTRIES=JP,<国コード>）。データは、パッケージを上げるたびに新しくなる。
- **人数まわりの設定**（環境変数。lyctl secrets set / ly.toml）: MAX_CLIENTS（同時に入れる人数。既定150）、MAX_PER_IP（同じ回線から入れる数。既定50。学校のWi-Fiなど同じ回線の人が多いときは増やす）。ログに [health] players=… cpu=…% lagP99=… が15秒ごとに出る（lyctl logs）。cpu が 80〜100% に近い、または lagP99 が 100ms を超えるなら、VM を大きくする（lyctl scale vm performance-1x --memory 1024）。[slow] は、回線が詰まった接続を切り離したしるし。
